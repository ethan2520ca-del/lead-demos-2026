# Шаблон: Кофейня, кофе с собой

Сделан заново на базе макета из «vibe-studio» (макет был полупустой: только первый экран и боилерплейт-цены). Теперь это рабочий лендинг: меню с ценами, доставка и самовывоз, «почему сюда», часы, адрес, форма заказа.

## Сборка

```
node "C:\Users\рс\.dsh\skills\galereya-45\scripts\build.mjs" kofeynya kino "<папка демо>"
```

## Слоты

`{{бизнес}}` — название кофейни; `{{город}}`; `{{телефон}}`; `{{адрес}}`; `{{ссылка-мессенджер}}` — Telegram/WhatsApp клиента.

## Что менять под клиента

- Меню: цены и позиции — из прайса карточки. Нет прайса — оставить шаблонные и предупредить: «цены уточнить у владельца».
- Фото зала/витрины — с карточки клиента (`.shot .ph` заменить на `<img src="assets/…">`). Нет фото — оставить заглушку, в карточке лида пометить `фото: сток`.
- Часы и адрес — из карточки, дословно.
- Кнопки «Заказать» — в мессенджер клиента.

## Проверка перед публикацией

1. Ниша совпадает: это кофейня/кофе с собой, а не ресторан.
2. На первом экране фото зала или витрины клиента (или честная заглушка без чужих людей).
3. Нет `{{…}}`, «Ваш текст здесь», «Собрано в Vibe Studio».
4. Цены, часы, адрес — из карточки.
5. Нет чужих городов.
6. Кнопка ведёт в его мессенджер.
7. На телефоне читается: меню не разъезжается, строки цен не рвутся.
8. Отзывы (если добавите) — дословно с Карт.
